# Student Directory

A responsive React + Vite student directory built with Bootstrap 5.

## Run locally

1. Install Node.js (LTS) if it is not installed.
2. Open this folder in VS Code.
3. In the VS Code terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the localhost URL printed by Vite.

## Features

- Responsive Bootstrap navbar and grid
- Breadcrumb navigation
- Student cards built from React props
- Search by name, ID, or major
- Working pagination
- View profile modal
- Add and delete student records
- Dismissible Bootstrap alert
- Responsive footer

Student data is held in React state and resets when the page is refreshed; there is no database attached.
